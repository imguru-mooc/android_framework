# [D0-5] WinSCP 설정 — 편집기 연동 + 북마크 4종

| 난이도 | 수행 시점 | 준비물 |
|---|---|---|
| ★☆☆☆☆ | Day 0 ★전원 필수 | `.ppk` 키(D0-4) |

> 🎯 **실습 목표** — WinSCP를 키 인증으로 연결하고, **"저장하면 서버로 자동 업로드"되는 편집기 연동**과 실습 경로 **북마크 4종**을 등록한다. Day 2~4의 "코드 수정 = WinSCP" 워크플로가 여기서 완성된다.

## Step 1. 설치 및 키 인증 세션

🖱 [winscp.net](https://winscp.net) → 설치 → 실행 → 새 사이트:
▸ 프로토콜 **SFTP** / 호스트·포트·사용자: D0-3과 동일
▸ **고급 → SSH → 인증 → 개인키 파일**: `aosp_ed25519.ppk` → 확인 → **저장**(이름 `aosp-build`) → 로그인

✅ **예상 결과:** passphrase 입력 후 좌(로컬)/우(서버) 2패널 표시

## Step 2. 편집기 연동 — 저장 시 자동 업로드

❓ **왜?** 서버 파일을 더블클릭 → 내 PC 편집기로 열림 → **Ctrl+S 하는 순간 서버에 업로드** — 이것이 실습 6-1~6-4에서 AOSP 소스를 고치는 표준 방법입니다.

🖱 **옵션 → 환경설정 → 편집기** → 추가 → *외부 편집기* 선택 → 본인 편집기 경로 지정(예: `Code.exe` / 메모장 가능) → 확장자 `*.*` → 확인

서버에서 아무 파일이나 열어 테스트:

```text
(WinSCP 우측 패널) ~/test_edit.txt 새로 만들기 → 더블클릭 → 편집기에서 내용 입력 → Ctrl+S
(PuTTY) cat ~/test_edit.txt   ← 방금 저장한 내용이 보이면 성공
```

✅ **예상 결과:** 저장 즉시 전송 창이 잠깐 떴다 사라지고, 서버 cat으로 내용 확인

## Step 3. 북마크 4종 등록

🖱 우측(서버) 패널에서 각 경로로 이동 → 주소창 옆 **★(북마크) → 추가**

| 북마크 | 경로 | 용도 |
|---|---|---|
| edu | `~/aosp/vendor/edu/` | 배포 실습 코드 |
| custom | `~/aosp/frameworks/base/core/java/android/os/custom/` | 실습 6-x |
| OUT | `~/aosp/out/target/product/emulator_car64_x86_64/` | 빌드 산출물 다운로드 |
| apex | `~/aosp/out/target/product/emulator_car64_x86_64/system/apex/` | Lab 4-3 |

💡 `out/` 하위는 첫 빌드(D0-2) 완료 후에만 존재합니다. 아직이면 앞 2개만 등록하고 Day 2 아침에 마저 등록하세요.

# 🔧 자주 발생하는 오류

| 증상 | 원인 | 해결 |
|---|---|---|
| 저장해도 서버에 반영 안 됨 | '내부 편집기'로 열었거나 로컬 사본 편집 | 옵션에서 외부 편집기 연결 확인, 반드시 **서버 패널에서** 더블클릭 |
| Too many authentication failures | Pageant에 키 과다 | Pageant 정리 또는 세션에 키 직접 지정 |
| out/ 경로 없음 | full build 미완료 | D0-2 완료 후 재시도 |

# 🚗 현업 활용 포인트
